# Expression variants, resonance and semantic review

## Purpose of the expression layer

An accepted meaning can be expressed clearly, compactly or movingly without being changed into a different claim. Expression is therefore a separate editable layer with its own revisions, clause mappings and review state.

Do not treat emotional force as a reason to increase certainty, remove a condition or introduce an obligation. A beautiful sentence that changes the argument returns to meaning review. It does not inherit approval because its source references still point somewhere plausible.

## Variant set

Provide explanatory, concise-maxim, reflective second-person and optional evocative variants. These are alternatives for the same reviewed meaning, not four opportunities to invent different doctrine.

Each variant has a stable identity, immutable revisions, intended role, conclusion references, clause mappings, clarity/resonance feedback and semantic-review state. Preserve rejected alternatives and why they were rejected. Do not let regeneration replace a user’s selected wording or locked decision.

The interface should make it easy to compare variants against the accepted meaning and original evidence. A “sounds better” choice is not automatically a “more faithful” choice.

## Clause mapping contract

Map substantive expression clauses to exact reviewed conclusion revisions. The inspector then resolves those conclusions to source spans and inference bundles. Store range/block identity and mapping status; do not reconstruct the mapping from matching words each time the screen renders.

Use an explicit category for neutral connective prose. Added metaphors, examples, practices or modern applications require separate classification and review for new implications. A connective label must not become a way to hide an unsupported promise.

A clause can depend on several reviewed conclusions together. Explain the joint role where needed. The coloring represents a contributor set, not a scientifically measured percentage or individual-word derivation.

## Semantic comparison dimensions

| Dimension | Example of a change requiring review |
|---|---|
| Scope | “In this situation” becomes “in every situation” |
| Certainty | “May help” becomes “will guarantee” |
| Conditions | A qualification about duty or context disappears |
| Obligation | An observation becomes a command |
| Agency | A recommendation about judgment becomes control over all feelings |
| Social implication | Fair action becomes unconditional submission or detachment |
| Metaphysical premise | A disputed premise is presented as established modern knowledge |
| Application | A modern exercise is attributed directly to Marcus |

Represent model-assisted comparisons as proposals with cited target spans and concise reasons. They can assist human attention but cannot certify that two sentences are philosophically equivalent.

## Editing and invalidation

Use stable editor block IDs and transaction-aware mapping. Inserted or substantially modified text must not inherit provenance solely because it was typed inside a colored mark. Clear or mark affected assessments stale. Preserve untouched mappings only when their identity and exact range remain reliable.

An undo can restore wording or structure, but it is not a shortcut that grants a new saved revision its predecessor’s approval. Explicitly discarding an unsaved draft restores the unchanged saved revision; that is different from saving a revised expression and later rewriting it back.

Changes to referenced meanings invalidate dependent expression assessments and manuscript uses. A historical expression may remain inspectable with its old conclusion references, but it must not be presented as grounded in the current meaning without remapping/review.

## User ratings

Let the user rate clarity and personal resonance separately from fidelity. Missing ratings remain missing. The model must not decide that an expression emotionally affects the user or infer personal preferences from a default fixture.

Record ratings with revision identity and user notes. A highly rated formulation can become stale after a meaning change. Preserve its historical rating rather than applying it automatically to a successor.

## Manuscript relationship

A manuscript block references an exact expression revision and a stable principle identity. Reordering changes display order, not source identity. A new expression revision should be proposed for adoption rather than silently replacing text in a reviewed manuscript export.

The compact core, fuller handbook and study view may use different expression roles, but all must resolve to the same reviewed meaning or explicitly identify their differences. Avoid generating the final book by summarizing earlier generated summaries.

## Evaluation and acceptance

Test deliberate overreach, changed conditions, added certainty, new metaphors, unsupported advice and apparently neutral connectives that actually introduce claims. Include a resonant but unfaithful variant that is rejected.

Browser checks should select a clause, inspect its exact conclusions/sources, edit inside a mark, observe lost/stale provenance, save/reload, compare versions and reject/approve on the correct revision. Keyboard and plain-reading paths must expose the same references.

This workstream is complete when the user can rewrite accepted meaning without silently changing its philosophical content or retaining invalid approval, and can explain why the selected wording is preferred on fidelity, clarity and personal grounds separately.
