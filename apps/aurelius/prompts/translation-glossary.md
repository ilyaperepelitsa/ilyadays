# Renderings already settled in this translation

Six passages were settled before yours. So that the same Greek word does not become a different English word from one passage to the next, prefer these renderings. They are preferences, not rules: where a passage's own argument needs another word, use it and say why in a note.

| Greek | English | When another word is right |
|---|---|---|
| ὁ κόσμος | the universe | "order" where the passage turns on the word's sense of order (as against a jumble); "the world" where the inhabited earth is meant |
| ἡ τῶν ὅλων φύσις, ἡ τοῦ ὅλου φύσις | the nature of the whole | |
| τὸ ὅλον | the whole | |
| φύσις (alone, as the power that orders things) | nature | |
| τὸ ἡγεμονικόν | the ruling part | |
| λόγος (the faculty, or the principle that governs) | reason | "account", "word", "saying" where that is the sense |
| λογικός | rational | |
| κοινωνικός | social | |
| νοῦς, νοερός | mind, of mind | keep one within a passage |
| διάνοια | thought | "mind" where the faculty is meant |
| ὁρμή | impulse | |
| φαντασία | impression | |
| ὑπόληψις | judgment | |
| δόγμα | principle | |
| συμφέρει | is good for | "benefits" where the sentence needs a verb with an object |
| περαίνεται | is carried through | never "is brought to its end", which is heard as "dies" |
| θεός, θεοί | god, the gods (lower case; names such as Zeus as they are) | |

For an impersonal subject (τις, ὁ … -ων) "a person … they" or "whoever … they" is fine; do not write "he" where the Greek does not single out a man.
