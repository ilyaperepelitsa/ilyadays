# Original-fixture numerical discovery artifacts

`fixture-analysis.npz` is generated by `npm run aurelius:analysis` from every canonical passage in `content/aurelius/fixture.json`. It contains full 3072-feature vectors, fitted PCA components/mean, projected coordinates, IDF values and exact row IDs. The text is original synthetic demonstration material, not Meditations.

Vectors are local hashed word/bigram TF-IDF features, not OpenAI embeddings. This explicitly labeled demonstration does not replace the requested production `text-embedding-3-large` / 3072-dimensional source index. No external request or paid inference is used.

`content/aurelius/analysis.json` contains the public map metadata, measured explained variance, source revision/hash coverage, actual PCA coordinates, full-space average-linkage cosine hierarchy and cluster cuts. It contains no private book. Real corpus artifacts belong under ignored `.aurelius/analysis/`, not in this directory.

The production build verifies all-chunk coverage and hashes with `scripts/aurelius-analysis-check.mjs`. Numerical tests independently transform the stored full vectors with the fitted state, compare measured variance and check that clustering receives the full input rather than the two plotted columns.
